# Preguntas

### 1. ¿Por qué la ruta utiliza un sustantivo y no una acción?
Porque la acción la define el método HTTP
### 2. ¿Qué diferencia existe entre una URI de colección y una URI de recurso individual?
Con la URI de colección se pueden obtener un conjunto de recursos, mientras que la individual es uno en específico.
### 3. ¿Por qué el método HTTP forma parte del significado de la operación?
Porque el método HTTP indica qué tipo de operación se quiere realizar sobre el recurso.
### 4. ¿Qué información debe viajar en la URI y cuál en JSON?
Por el URI viaja información que identifique al recurso, mientras que en JSON viaja información para crearlo o modificarlo
### 5. ¿Qué código HTTP permite distinguir una consulta exitosa, una creación y un recurso inexistente?
200 para consulta exitosa, 201 para creacion y 404 no encontrado.
